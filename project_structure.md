# Project Structure

This document provides an overview of the project's file structure and organization.

## Root Directory Files
- `README.md` - Main project readme file
- `index.html` - Main index page
- `apps.html` - Apps section page
- `gallery.html` - Gallery page
- `flashcard-app.html` - Flashcard application page
- `msa.html` - MSA page
- `PROJECT_STATUS.md` - Project status documentation
- `Continuation_Notes.md` - Continuation notes
- `project_planning.md` - Project planning documentation
- `mla_chatbot_requirements.md` - MLA chatbot requirements
- `# chatbot_mla_requirements.md` - Backup of chatbot requirements
- `CNAME` - CNAME file for DNS configuration
- `system_prompt.txt` - System prompt for AI interactions
- `site.webmanifest` - Web app manifest file

## Assets Directory (`assets/`)
Contains all media and third-party resources:
- **css/** - CSS stylesheets
- **img/** - Image assets
  - **about/** - About page images
  - **abstract/** - Abstract illustrations and animations
  - **misc/** - Miscellaneous images
  - **person/** - Person-related images
  - **portfolio/** - Portfolio images
  - **services/** - Service images
- **js/** - JavaScript files
- **apps/** - App-specific images
- **arduino/** - Arduino-related images and screenshots
- **landscapes/** - Landscape images
- **scss/** - SCSS style files
- **ticker/** - Ticker/animated elements
- **urban/** - Urban imagery
- **vendor/** - Third-party libraries and frameworks

## Components Directory (`components/`)
- **chat/** - Chat component files:
  - `chat-section.html` - Chat section HTML
  - `chat-section.css` - Chat section styles
  - `chat-section.js` - Chat section JavaScript

## CSS Directory (`css/`)
- `site.css` - Main site stylesheet

## Favicons Directory (`favicons/`)
- Favicon files for different sizes and formats including:
  - `favicon.ico` 
  - `favicon-16x16.png`
  - `favicon-32x32.png`
  - `android-chrome-192x192.png`
  - `android-chrome-512x512.png`
  - `apple-touch-icon.png`
  - `about-portrait-1.webp`

## Forms Directory (`forms/`)
- `contact.php` - Contact form processing script

## JS Directory (`js/`)
- `nav.js` - Navigation JavaScript

## Partials Directory (`partials/`)
- `footer.html` - Footer partial HTML
- `nav.html` - Navigation partial HTML

## Wiki Directory (`wiki/`)
Documentation for the project with two main sections:
- **docs/** - Documentation files organized by topic:
  - **arduino/** - Arduino-related documentation and examples
  - **python/** - Python tutorials and examples including:
    - Housing price prediction exercises
    - Linear regression tutorials
    - Number guessing games
    - Opening virtual environments
    - Python installation guides
  - **webdev/** - Web development documentation including MkDocs guides
- **site/** - Generated documentation website files:
  - HTML pages for each documentation section
  - CSS styles and fonts
  - JavaScript files
  - Search functionality files

## Not in Use Directory (`notinuse/`)
- Contains files that are not currently active but may be referenced or used later:
  - `gallery.html` - Older gallery page (backup)

## Code Blocks Directory (`code_blocks/`)
- Contains code block images and assets for documentation examples
