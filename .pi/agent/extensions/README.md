# Web Development Helper Extension

This extension adds web development tools to Pi that assist with analyzing and improving the Tonis Praks Universe website.

## Features

1. **HTML Structure Analysis** - Analyzes HTML files for best practices, accessibility issues, and optimization opportunities
2. **Template Generation** - Creates reusable HTML component templates (headers, footers, cards)
3. **CSS Optimization Suggestions** - Provides insights and recommendations for CSS improvements  
4. **Best Practices Guidance** - Offers general web development best practices tailored to this project

## Commands Available

- `/web_dev_help` - Show help information for web development tasks
- `/analyze_html <file>` - Analyze an HTML file for structure and issues
- `/generate_template <type>` - Generate HTML component templates (header, footer, card)

## Tools Provided

- `analyze_html_structure` - Detailed HTML file analysis
- `generate_html_template` - Component template generation
- `optimize_css` - CSS optimization suggestions
- `suggest_web_best_practices` - General web development advice

## Usage Examples

```
/analyze_html index.html
/generate_template header
/web_dev_help
```

The extension is designed to help maintain and improve the quality of a modern web development project with focus on:
- Semantic HTML structure
- Responsive design principles  
- Accessibility standards
- Performance optimization
- Best practices for web development
