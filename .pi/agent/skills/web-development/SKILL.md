# Web Development Assistant

Use this skill to help with web development tasks, including HTML structure analysis, CSS optimization, component templating, and best practices for web projects.

## Steps

1. Analyze the current project structure and files
2. Identify opportunities for improvement in HTML, CSS, and JavaScript
3. Generate appropriate templates for components (headers, footers, cards, etc.)
4. Provide suggestions for optimization and best practices
5. Help implement improvements to the codebase

## Available Tools

- `analyze_html_structure` - Analyze HTML files for structure and issues
- `generate_html_template` - Create reusable HTML component templates 
- `optimize_css` - Analyze and suggest CSS optimizations
- `suggest_web_best_practices` - Provide general web development best practices

## Examples

### Ask about web development
"Review my index.html for accessibility and SEO issues"

### Request template generation  
"Generate a responsive footer template with social media links"

### Get optimization suggestions
"Suggest improvements for my CSS files to make them more efficient"
