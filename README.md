# Tonis Praks Universe

A personal portfolio and creative project showcase website.

## Project Structure

```
├── index.html          # Foundation test / landing page
├── msa.html            # MSA (Machine Learning) project page
├── gallery.html        # Photo gallery
├── flashcard-app.html  # Flashcard application
├── apps.html           # Apps showcase
├── css/                # Global styles
├── partials/           # Shared HTML components (nav, footer)
├── assets/             # Static assets (images, scripts, styles)
│   ├── img/
│   ├── css/
│   ├── js/
│   └── ticker/
├── wiki/               # MkDocs-based documentation
├── photos/             # Photo assets
├── favicons/           # Favicon files
└── forms/              # Form templates
```

## Features

- **Dark Theme**: Custom dark UI with accent colors
- **Responsive Design**: Mobile-first approach with Tailwind CSS
- **Modular Structure**: Reusable partials for navigation and footer
- **Interactive Elements**: Custom cursor, particle backgrounds
- **Multiple Sections**: Gallery, apps, flashcards, wiki

## Tech Stack

- HTML5
- Tailwind CSS (CDN)
- Google Fonts (Syne, Space Mono, DM Sans)
- Vanilla JavaScript
- MkDocs (for wiki/documentation)

## Getting Started

1. Clone the repository
2. Open `index.html` in a browser or use a local server
3. For wiki, run `mkdocs serve` in the `/wiki` directory

## Customization

- Theme colors are defined in `tailwind.config` within HTML files
- Global styles in `css/site.css`
- Fonts can be swapped via Google Fonts link in the head
